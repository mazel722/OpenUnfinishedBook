# OpenUnfinishedBook

基于 Ren'Py 的《未竟之书》解包资源，供学习与研究使用。仓库包含脚本、图片、音频等可供本地运行与研究的资源。

## 快速开始

1. 克隆或下载本仓库到本地。
2. 在 Ren'Py 中创建一个新项目。
3. 将本仓库的 `game/` 文件夹复制到新项目目录中并覆盖原有内容。
4. 在 Ren'Py 启动器中运行项目以预览内容。
